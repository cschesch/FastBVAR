# Frozen reference

FastBVAR is derived from Ferroni and Canova's
[BVAR toolbox](https://github.com/naffe15/BVAR_).

The immutable reference implementation is the Git submodule at
`reference/BVAR_`, pinned to:

```text
3975e6597cb23d82e4ebad162af29b2a1105b395
```

Do not edit files in the submodule. Initialize it after cloning with:

```matlab
!git submodule update --init --recursive
```

The GPL-3.0 license and upstream attribution are retained.
